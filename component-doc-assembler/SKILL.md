# Component Doc Assembler

Read [shared setup and evidence](../shared/setup-and-evidence.md). If Persian text, captions, or alt text need editing, read [the full Persian guide](../shared/persian-writing.md). Assemble the sections selected for this component; do not add new policy while merging.

Accept the writer's approved Markdown drafts and the visual skill's verified images, captions, alt text, and manifest. Match each image to the specific section and claim it illustrates. Keep figures close to their text and use relative Markdown image paths when the images are delivered in the same package. Preserve exact source property and variant names in both languages. When bilingual output is selected, produce separate `.fa.md` and `.en.md` files with corresponding images or a shared language-neutral visual where both versions truly match. Do not put English captions on a Persian image or vice versa.

Check the final package: every selected section appears once in the requested language(s); every image path resolves; captions and alt text match the visible image; figures have verified dimensions; there are no placeholders, internal evidence notes, raw Figma binding suffixes, or unsupported claims. If an image remains blocked, deliver the text with a clear missing-asset note outside the publication Markdown and leave no broken image link. Return the paths to the Markdown files, image directory, and editable Figma visuals.
