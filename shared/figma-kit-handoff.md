# Figma kit handoff

Create the neutral kit in a new page of the Figma design file chosen by the user. Do not copy source templates or product assets from another organization. Use the reusable families and visual defaults in [visual-kit-spec.md](visual-kit-spec.md). After building, record the page URL and component set URL in the user's `component-docs.json`; do not commit that project-specific configuration to the public repository.

The page should include a concise usage note, a neutral demonstration component, and editable FA/EN examples for every family. Verify each variant's structure and a sample exported image in a fresh Figma read. Sharing a page URL does not grant access if the parent file's permissions prevent it; confirm the intended recipients can view or duplicate the file before announcing it as shared.
